ЩО ПІДСТАВИТИ
1) Реальний QR-код:
   - замініть assets/qr-donation.svg на ваш qr-donation.png (або svg)
   - і в index.html знайдіть "Відкрити посилання на збір" та вставте реальний URL.

2) Тексти:
   - секції "Партнери" і "Звітність" зараз з заглушками.
   - блок "історія (допишемо)" теж заглушка.

ПУБЛІКАЦІЯ НА GITHUB PAGES
- Завантажте всю папку в репозиторій.
- Settings → Pages → Deploy from a branch → main → /(root)
