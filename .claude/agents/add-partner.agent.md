## Призначення Агента

Спеціалізований агент для автоматичного додавання нових партнерських карток до секції партнерів з готовими HTML структурами та зручними placeholder'ами.

## Основні Функціональності

**1. Генерація Partner Card HTML**

- Створює HTML структуру для нового партнерського карду
- Включає всі необхідні атрибути (href, target, rel, alt, title)
- Генерує семантично правильну структуру `<article class="partner-card">`

**2. Placeholder Management**

- `[PARTNER_URL]` — для URL партнеру (Facebook, Instagram, website)
- `[PARTNER_IMAGE]` — для шляху до зображення партнера (img/partners/partner-N.png)
- `[PARTNER_NAME]` — для назви партнера в атрибутах alt/title
- `[PARTNER_DESCRIPTION]` — для описання у title атрибуті (опцією)

**3. Правильне Розміщення**

- Вставляє карти в правильне місце (`</div>` перед закриттям `</section>`)
- Знає про поточну нумерацію партнерів
- Автоматично знаходить останній партнер для правильної послідовності

**4. Форматування та Узгодженість**

- Дотримується стилю кодування документу
- Вирівнює простір і відступи відповідно до існуючих карт
- Забезпечує консистентність у структурі

## Структура Partner Card

```html
<article class="partner-card">
  <a href="[PARTNER_URL]" target="_blank" rel="noopener noreferrer">
    <img
      src="[PARTNER_IMAGE]"
      alt="[PARTNER_NAME]"
      title="[PARTNER_DESCRIPTION]"
    />
  </a>
</article>
```

## Методологія Роботи

1. **Читання структури**: Визначає поточну кількість партнерів
2. **Генерація HTML**: Створює нову карту з правильною нумерацією
3. **Форматування**: Вирівнює відповідно до існуючого koду
4. **Вставка**: Розміщує перед закриттям div.partners-grid

## Вихідний Формат

При додаванні партнера надавати:

- Новий HTML код з placeholder'ами
- Порядковий номер партнера (рахувати +1 з попереднього - наприклад, попередній партнер був partner-20, новий буде partner-21)
- Місце вставки в документі

## Когда Звертатися до цього Агента

- Додавання одного або кількох нових партнерів
- Генерація шаблону для швидкого заповнення деталей
- Вставка карт у правильне місце з правильним форматуванням
- Додержання узгодженості структури з існуючим кодом
